# Minha Primeira Viagem com Milhas — Projeto DIO

> Caderno temático criado com NotebookLM para aprender a usar o programa
> Livelo do zero e conquistar a primeira viagem com milhas aéreas.

---

##  Contexto e Objetivos

### Por que escolhi esse tema?

Escolhi o tema **Minha Primeira Viagem com Milhas** porque quero aprender
a usar o programa Livelo para acumular pontos nas compras do dia a dia e
trocá-los por passagens aéreas — sem precisar pagar do bolso pela viagem.

Nunca usei um programa de fidelidade antes. Tenho dúvidas sobre como
ganhar pontos de forma eficiente, quais parceiros valem a pena, como
transferir para companhias aéreas (Smiles, TudoAzul, Latam Pass) e quando
é melhor resgatar como cashback em vez de milhas.

### Objetivos de Estudo

| O que quero entender | O que quero conseguir fazer |

| Como o programa Livelo funciona | Criar minha conta e ativar o acúmulo |
| Quais parceiros rendem mais pontos | Identificar os melhores cartões e lojas |
| Como funciona a transferência para cias aéreas | Executar minha primeira transferência Livelo → Smiles |
| Diferença entre milhas e cashback | Decidir qual opção é melhor para o meu perfil |
| Como calcular quantos pontos preciso | Planejar uma viagem real com meta de pontos |

### Ferramenta utilizada

Para organizar e aprofundar o estudo, utilizei o **NotebookLM** (Google)
como caderno temático inteligente — fazendo upload das fontes selecionadas
e interagindo com a IA para extrair resumos, comparações e respostas às
minhas dúvidas reais sobre o Livelo.
